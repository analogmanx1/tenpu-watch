📊 副作用検索

PMDAで添付文書を検索 ↗
使い方

薬剤名(一般名・販売名)を入れて候補をクリックすると、添付文書の「副作用」に書いてある項目を頻度(%)の高い順に並べて出します。 ⚠ 重大=重大な副作用、灰色の枠=臓器などの区分(肝臓・消化器など)。「頻度不明」は数が多いので畳んであります(クリックで表示)。 副作用の書き方がまったく同じ製品(後発品どうしなど)は1つにまとめて「ほかに同じ記載の製品 ◯件」と出します。ひらがな/全角半角の違いは気にしなくてOK。

一覧データ: 2026-10-25 時点・製品 11,235件(副作用の記載の違い 3,230通り)。元データはPMDAの添付文書 ↗の「11. 副作用」の章(自宅PCの自動更新が、改版された添付文書を毎日確認して差し替えます)。 添付文書の副作用は、ほとんどが「5%以上」「1～5%未満」のような幅(帯)で書かれています。項目ごとのピッタリの%は、書いてある添付文書のぶんだけ出ます。 同じ帯の中の並びは添付文書の表の順です(帯の中での多い・少ないは分かりません)。表の形になっていない古い書き方の添付文書は、本文をそのまま載せています。 必ず最新の添付文書で確認してください。

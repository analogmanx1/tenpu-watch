🧬 薬理作用検索

PMDAで添付文書を検索 ↗
使い方

薬剤名(一般名・販売名)を入れて候補をクリックすると、添付文書の「18. 薬効薬理」(作用機序=どうやって効くのか・薬理作用)を出します。 長い薬は「作用機序」と最初の項目だけ開いて、ほかの項目は畳んであります(クリックで表示)。もっと詳しく知りたいときは、下の「📘 IF(PDF)」からインタビューフォームの「Ⅵ. 薬効薬理に関する項目」を開いてください。 書き方がまったく同じ製品(後発品どうしなど)は1つにまとめて「ほかに同じ記載の製品 ◯件」と出します。ひらがな/全角半角の違いは気にしなくてOK。

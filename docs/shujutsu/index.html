🏥 術前休薬・禁忌チェック

PMDAで添付文書を検索 ↗
使い方

添付文書の「禁忌」「重要な基本的注意」「特定の背景を有する患者」「相互作用」などの章から、手術に触れている文を集めて一般名ごとにまとめた一覧です。 薬剤名(一般名・販売名)や薬効(例: 抗血小板)、文中の言葉(例: 14日)で絞り込めます。スペース区切りでAND。ひらがな/全角半角の違いは気にしなくてOK。 区分ボタンで出し分け(🚫 禁忌=禁忌の章に手術の記載 / ⏸ 手術時の対応あり=休薬・中止・◯日前・用量調節などの記載 / 📎 その他=それ以外の手術関連の注意。最初は畳んであります)。 黄色のマーカーが手術に触れている文。「出典 ↗」でその添付文書(PDF)が開きます。

一覧データ: 2026-09-21 時点・一般名 330種類(禁忌 63/手術時の対応あり 146/その他 121)。元データはPMDAの添付文書 ↗(自宅PCの自動更新が、改版された添付文書を毎日確認して差し替えます)。 載っているのは「添付文書に手術の記載がある薬」だけです。現場で術前に休薬する薬でも、添付文書に記載が無ければ載りません(院内の術前休薬一覧・各学会ガイドラインの代わりにはなりません)。 決まった言葉(手術・術前・術後・周術期 など)で機械的に拾っているため、言い回しによっては漏れ・余計なものが混じることがあります。 メーカーごとの細かい言い回しの違いは、いちばん多い表現にまとめています。 必ず最新の添付文書で確認してください。

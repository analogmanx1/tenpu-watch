# ツールの追加のしかた

1. `_template.html` をコピーして、好きな名前で保存(例: `accumulation.html`)
   - ファイル名は半角英数字がおすすめ(URLになるため)
   - 先頭が `_` のファイルは一覧に載りません(ひな形用)
2. `<title>` と `<meta name="description">` を書き換える → トップページのカードとメニューに自動で載る
3. 中身を作る(HTML + JS だけで完結。外部ライブラリ不要)
4. GitHubに push すれば公開される(毎日の自動実行(7時・17時)でも index.html が再生成されて一覧に反映)

※ `watch/` `assets/` `index.html` は自動生成で上書きされるので、手で編集しないこと。
  このフォルダ(tools/)は自動生成の対象外なので安心して編集してOK。

※ トップページ(ホーム)に「薬剤師ツールボックス」以外の項目を足したいときは、
  リポジトリ直下の `site/home.json` に1項目追加(READMEの「サイトの階層」参照)。

## いま入っているツール
- `gamma.html` ガンマ計算(γ計算アシスタント)。元は `G:\マイドライブ\AI\chrome拡張機能\ガンマ計算アシスタント\スマホ版\ガンマ計算アシスタント_1ファイル版.html`。
  計算ロジックはそのまま、見た目だけ共通ヘッダー付きに直して CSS を `.gapp` の中に閉じ込めた(PWA用の manifest / sw.js は外した)
- `dialysis.html` 血液透析による薬物除去率。Murakami M, et al. Blood Purif 2021 の回帰式(log10・小数2桁・0未満/100超はそのまま出す+注意書き)。
  平田純生先生のサイト(hirata.softsync.jp/dialysis_calc)の計算機と同じ式で、5パターンの実値で一致を確認済み
- `accumulation.html` 蓄積率(蓄積係数)R。半減期t½と投与間隔τから R＝1÷(1−e^(−0.693×τ/t½)) で計算(線形動態・等間隔投与を仮定)。
  時間/日の単位切り替え・投与間隔のかんたん入力チップ・定常状態到達の目安(t½×4〜5)つき。R>20で単位間違いの注意を表示
